# Especificaciones de rebanadas

Una página por rebanada, escrita por el Planificador o el Constructor antes de codificar: objetivo, paquetes tocados, criterios de hecho, casos de prueba y presupuesto de tokens. El nombre del archivo coincide con el de la rama: `docs/specs/<rebanada>.md` para `rebanada/<rebanada>`.

La plantilla `PLANTILLA.md` llega con la rebanada "Fábrica de agentes".
