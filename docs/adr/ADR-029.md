## Decisión

No se paga la integración continua. Para usar los minutos gratuitos de GitHub Actions, Jesús pone el repositorio en público o en privado según le convenga.

## Alternativas

Subir el límite de gasto de GitHub Actions; recortar minutos con menos jobs o menos pushes; volver a los ejecutores propios, retirados en el PR #42.

## Consecuencias

Mientras sea privado, la CI puede volver a bloquearse por el límite de gasto; mientras sea público, los ejecutores estándar de GitHub no cuestan. Todo lo que se publica, historial incluido, se da por público para siempre aunque el repositorio vuelva a privado. Antes de la primera publicación se revisa el historial completo en busca de secretos y de datos que no deban salir. En público, los PR de personas externas necesitan aprobación para ejecutar la CI y no se usan ejecutores propios. Los roles de OIDC de Bedrock y Vertex siguen atados al identificador del repositorio y a main, así que una bifurcación no puede asumirlos. Al volver a privado, GitHub borra las estrellas y los seguidores, y las bifurcaciones públicas siguen públicas. Decisión de Jesús del 30-9-2026 en la sesión de dirección.
