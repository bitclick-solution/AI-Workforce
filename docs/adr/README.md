# Registros de decisiones de arquitectura

Cada decisión del miércoles de decisiones es un ADR aquí y en la base **Decisiones** del tablero de Notion antes de 24 horas. El Cronista redacta; Jesús aprueba. La redacción del archivo y de la base debe coincidir.

Convención: `ADR-NNN.md`, primera línea con el estado del documento (`VIGENTE`, `SUPERSEDED por <ruta>`, `REGISTRO HISTÓRICO`, `LISTO PARA ENCARGO`) y secciones Contexto, Decisión, Alternativas, Consecuencias, Estado en el tablero.

Los ADR-001 a ADR-011 llegan con la rebanada "Fábrica de agentes".
