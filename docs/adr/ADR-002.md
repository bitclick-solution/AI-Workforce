## Decisión

TypeScript de extremo a extremo (Node 22, pnpm, Turborepo, Zod). Temporal como motor de ejecución durable. Vercel AI SDK como pasarela multiproveedor (Anthropic vía Bedrock UE o Vertex UE, Mistral, locales). MCP como contrato de herramientas con gateway propio; Nango autoalojado para la cola larga; n8n como servidor MCP para automatizaciones a medida. PostgreSQL 16 con RLS y pgvector, Drizzle. Next.js, Tailwind, shadcn/ui. Centrifugo para tiempo real. Better Auth. Stripe. Langfuse, OpenTelemetry, Sentry. Docker Compose en nube europea (Hetzner, Scaleway u OVHcloud) con Dokploy; mismo bundle para on-premise.

## Alternativas

Python en servidor; máquina de estados propia; Restate o Inngest (reversible en fase 0); Managed Agents como núcleo; LangGraph, CrewAI o Mastra; Kubernetes desde el inicio.
