## Decisión

Equipo: Jesús y los agentes Fable 5 necesarios con ocho roles (Planificador, Constructor, Revisor, Evaluador, Cronista, Diseñador, Operador, Investigador) definidos en .claude/agents/. Unidad de trabajo: la rebanada, con estados Propuesta, Lista, En curso, En revisión, Demostrada, Hecha, Bloqueada. Ciclos de dos semanas con apetito fijo, junta diaria de 20 minutos, miércoles de decisiones, viernes de demo. Límite de tres rebanadas en curso. Zonas críticas con revisión humana en CODEOWNERS. Notion como único tablero para personas, GitHub como fuente de verdad del código, sincronizados por los agentes vía MCP y rutinas nocturnas del Cronista y del Evaluador. Presupuesto de tokens por rebanada.

## Alternativas

Scrum completo; Shape Up de seis semanas; Kanban sin ciclos; GitHub Projects o Markdown local como tablero (esquema idéntico, alternativa si Notion falla).

## Consecuencias

Regla de parada: más de tres PR esperando dos días detiene la producción hasta vaciar la cola. Diez reglas del tablero; la retro cambia una por ciclo. Rutinas nocturnas del Cronista y del Evaluador: se ejecutan como Rutinas de Claude Code (vía primaria, decisión de Jesús del 2026-09-19); el workflow de GitHub Actions rutinas-nocturnas.yml queda como respaldo documentado y apagado.
