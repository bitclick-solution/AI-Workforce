# ADR-012 · Protección de main por método, no por GitHub

## Decisión

El repositorio AI-Workforce sigue privado y la organización en el plan Free de GitHub, donde las reglas de rama no se aplican. La protección de main se aplica por método: solo Jesús (3rChuss) fusiona; nada se fusiona sin CI en verde, veredicto del Revisor y lista de hecho rellena; en zonas críticas, además, aprobación explícita de Jesús en el PR. Ninguna sesión de agente fusiona, aunque la cuenta bitclicklabs tenga permiso. La configuración de protección queda guardada en GitHub para que se aplique sola si el plan cambia.

## Alternativas

Hacer público el repositorio; pasar la organización a GitHub Team; mover el repositorio a una cuenta personal con GitHub Pro.

## Consecuencias

El Cronista comprueba cada noche quién fusionó cada PR y con qué checks, y anota en el resumen de dirección cualquier fusión que incumpla la regla. El riesgo «La protección de main no se aplica» queda abierto con esa señal. En los ajustes del repositorio, disponibles en el plan Free, Jesús deja squash como único método de fusión y activa el borrado automático de ramas al fusionar. Se revisa si el repositorio se abre a colaboradores externos o si cambia el plan.
