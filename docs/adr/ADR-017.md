## Decisión

La residencia de la inferencia en la UE es un requisito del producto, no una preferencia. Comprobado el 2026-09-22 en la documentación de Anthropic: la API de primera parte y Claude Platform on AWS solo ofrecen las geografías de inferencia «global» y «us», y el único workspace geo es «us»; ninguna de las dos mantiene los datos de inferencia en Europa. Por eso la inferencia de Anthropic se contrata por Amazon Bedrock en regiones de la UE, con Google Vertex AI en regiones de la UE como segunda vía, tal como fija el ADR-002, y esa elección se hace explícita como consecuencia de la residencia. La ruta de Anthropic se implementa con el SDK oficial de Anthropic (cliente Mantle de Bedrock o cliente de Vertex, que exponen la API de Messages con la misma forma que la primera parte) detrás del puerto de packages/models; el AI SDK de Vercel queda como pasarela para Mistral, para modelos locales y para el proveedor determinista de la integración continua, y el puerto de packages/models es la única interfaz que ve el bucle del agente. Se aceptan y se documentan las funciones que no existen en Bedrock ni en Vertex: conector MCP nativo (lo cubre nuestro gateway), lotes, Files API, fallbacks de servidor (se implementan en cliente), presupuestos de tarea (los aplica el bucle con el presupuesto de la política), herramientas de servidor de búsqueda, fetch y ejecución de código (el conocimiento entra por nuestro índice, ADR-009), Agent Skills por API (las habilidades se inyectan en el prompt de la versión de puesto) y Managed Agents. Los usos internos sin datos de clientes (Revisor en la integración continua, fábrica de agentes, evals con datos sintéticos) pueden usar la API de primera parte. Si Anthropic publica una geografía de inferencia o un workspace geo en la UE, este ADR se reabre para pasar a la primera parte con paridad total.

## Alternativas

API de primera parte con inference_geo (hoy solo «us» y «global»); Claude Platform on AWS (mismas geografías, workspace geo «us»); Microsoft Foundry (zona de datos de EE. UU.); Mistral como único proveedor (pierde calidad en razonamiento y herramientas); AI SDK para toda la ruta de Anthropic (retraso en funciones nuevas y forma Converse en Bedrock); renunciar a la residencia UE para ganar funciones.
