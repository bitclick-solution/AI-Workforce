# Servicio de documentos

Servicio aislado en Python para OCR de respaldo (Tesseract o Docling) y generación de PDF desde plantillas HTML con Chromium sin interfaz. La extracción principal la hacen los modelos multimodales por el AI SDK; este servicio cubre el respaldo y la generación con marca.

- Se consume como imagen; nunca como biblioteca en el código TypeScript.
- Llega con la rebanada "OCR y extracción de facturas y contratos; generación de documentos con marca" de la fase 2.
