# Servicio de detección de datos personales

Servicio aislado en Python sobre Presidio. Actúa como guardia de entrada y de salida: detecta datos personales antes de indexar conocimiento y antes de que una respuesta salga a un tercero; excluye categorías especiales por defecto.

- Se consume como imagen desde el motor; nunca se importa como biblioteca en el código TypeScript.
- Llega con la rebanada del índice de conocimiento v1. Este directorio fija la frontera y la convención de empaquetado.
